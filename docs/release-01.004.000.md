# PSteroid5 01.004.000 — pattern authoring

Completes the pattern designer mechanic omitted from the previous test candidate.

- FILL selects a closed ship region, including curved hulls, divided areas and holes.
- Design a freeform repeating tile with the controller or touchpad, using mirrored
  strokes, per-line colours/widths, move/erase/paint and undo/redo.
- Grid, hex, triangle, diamond, ribs and crosshatch starters, blank artwork,
  live ship preview, repeat scale, zoom/pan/minimap, apply/cancel/remove/test flight.
- Linked fill recipes refit with hull edits and scaling, survive drafts and online
  saves, and reopen in the browser editor. Pending tile edits can be recovered.
- Local pattern library and browser-compatible CSP1 file import/export.
- Preserves the parallax stars, arcing shooting stars and power-up trail styles
  from 01.003.000, along with the same title identity and save paths.

The local shelf replaces the reference's test-database-only cloud pattern library.
Generation budgets reject dense artwork atomically; CSP1 keeps its shared 4,096
character limit. Hardware acceptance remains pending until recorded for this exact
candidate. No store publication is authorized by a successful build or transfer.
