# PSteroid5 01.004.002 — vector launcher artwork

Launcher artwork now matches the game: a flat multicolour line ship, trails
behind its rear edge, hollow polygon asteroids, star dots and a shooting-star arc.

remain byte-identical to that validated build. Package identity, icon, source
provenance and both folder copies are revalidated after the artwork refresh.
The original console installation is preserved for rollback during deployment.
