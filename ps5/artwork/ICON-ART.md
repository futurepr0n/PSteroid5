# Flat vector launcher artwork

Selected master: `icon-vector-master.png`. PS5 export: `../sce_sys/icon0.png`.
Run `../Build-Icon.ps1` to export an opaque, non-interlaced 512×512 RGB PNG.
The original icon and its drawing recipe remain here as reference files.

Created using the built-in imagegen tool, with the original icon as the style
reference. The first shaded concept was rejected because it did not match the
game. The selected image uses empty outline polygons, line-drawn ship geometry,
coloured trails behind the ship, star dots and a thin shooting-star arc.

## Final generation prompt

Redesign this PSteroid5 launcher icon while strictly preserving the reference's
FLAT TWO-DIMENSIONAL VECTOR ARCADE GAME AESTHETIC. This must look like actual
classic Asteroids vector gameplay with a colourful custom line-drawn ship, not
spaceship concept art. Square composition, opaque pure black background. EVERY
spaceship and asteroid is ONLY A THIN CLOSED POLYLINE OUTLINE WITH COMPLETELY
BLACK EMPTY INTERIOR. NO solid surfaces, NO shaded panels, NO faceted rocks, NO
craters, NO materials, NO 3D, NO dimensional bevels, NO shadows, NO volumetric
lighting, NO realistic spaceship, NO thick metal frames. Draw one simple
asymmetric angular arrow/triangle custom ship as cyan, magenta and lime line
segments near the centre, pointing diagonally up-right, with perhaps two simple
inner line segments like a user-built line design. Its rear is clearly down-left.
Short trails made of thin cyan/magenta/lime lines and tiny square pixels attach
DIRECTLY to the rear points of THIS SHIP and extend a short distance backwards
down-left. Trail pixels fade into black; keep them modest and game-like, not thick
laser beams. Three unrelated asteroids are plain empty irregular 6-to-8-sided
polygon outlines in pale grey, like the reference game: one at upper-left, one
far-right, one small upper-right. No engines, booster dots or trails on asteroids;
keep asteroids spatially well separated from ship exhaust. Sparse simple white,
dim blue, pink and gold star dots of different sizes/depths; ONE fine white curving
shooting-star streak in the upper background, understated. Preserve the exact bold
flat white sans-serif wordmark 'PSTEROID5' at the bottom, with generous margins.
Flat vector lines, sparse black negative space, bright readable silhouettes. At
512px the principal ship outline should have a 3 to 4px stroke and asteroid
outlines 2 to 3px strokes. IMPORTANT: all the objects must have EMPTY BLACK
interiors, outlined only. The only colourful area is ship linework and thin
pixel/ribbon exhaust behind it. The goal is an honest icon for a simple 2D
line-art game, not a glossy illustrated cover. Original input is the style
reference.
